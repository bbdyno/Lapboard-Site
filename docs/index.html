Lapboard: Multi Stopwatch

Time many people at once.

  • Run as many stopwatches as you need at the same time, organized into groups.
  • Type a name or bib number and tap Start — it's added and timing in one step.
  • Undo an accidental start, stop or reset within a few seconds.
  • Race mode: one clock, tap once per finisher, add names later.
  • Laps, time adjustment, stats, countdowns, history and CSV export.
  • iPhone, iPad and Apple Watch, with Home Screen widgets and Live Activities.

Every feature is free. The free version shows ads, which you can remove with a single purchase.
